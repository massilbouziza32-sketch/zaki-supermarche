# Zaki Supermarché

نسخة أولية عربية RTL لنظام تسيير سوبر ماركت، مبنية بـ HTML وCSS وJavaScript، قابلة للنشر على GitHub Pages.

## تشغيل سريع

1. ارفع جميع ملفات المجلد إلى مستودع GitHub.
2. من المستودع افتح **Settings → Pages**.
3. اختر **Deploy from a branch** ثم `main` و`/(root)`، ثم Save.
4. انتظر نشر الموقع وافتح الرابط الذي يعطيك GitHub.
5. سجّل الدخول التجريبي:
   - اسم المستخدم: `admin`
   - كلمة المرور: `Admin123!`

## الوظائف الموجودة في النسخة الأولية

- لوحة قيادة لمبيعات اليوم والفواتير والأرباح التقديرية والتنبيهات.
- نقطة بيع POS وسلة مشتريات.
- إدارة المنتجات والأسعار والكميات والباركود والصلاحية.
- تسجيل المشتريات وإضافة الكميات للمخزون.
- الزبائن وتسجيل ديونهم وتحصيل الدفعات.
- أرشيف الفواتير والطباعة وإلغاء الفاتورة وإرجاع الكمية.
- تقارير وتصدير CSV.
- حسابات محلية تجريبية للأدوار: مدير، كاشير، مسؤول مخزون، مسؤول ديون.
- سجل عمليات ونسخة احتياطية JSON.
- PWA مبدئي للتثبيت والعمل مع تخزين محلي.

## تنبيه أمني مهم جداً

هذه **نسخة MVP تجريبية تعمل على الجهاز نفسه باستخدام localStorage**. ليست جاهزة لتسيير أموال ومخزون متجر حقيقي متعدد الأجهزة. بياناتها ليست متزامنة بين الهاتف والحاسوب، وحسابات العمال المحلية ليست مصادقة آمنة؛ كما أن كلمة المرور التجريبية ظاهرة في الكود. لا تضع بيانات زبائن حقيقية أو تعتمد عليها محاسبياً قبل ربط Supabase Auth وقاعدة بيانات مع سياسات RLS وخادم موثوق لإنشاء حسابات العمال.

## Supabase

يوجد ملف `supabase/schema.sql` كبداية لتصميم قاعدة البيانات السحابية. يحتاج مراجعة وتطبيقاً واختبارات قبل تشغيل بيانات حقيقية. لا تضع `service_role` key في JavaScript أو في GitHub. في الواجهة الأمامية لا تستخدم إلا المفتاح العام anon/publishable بعد إعداد RLS.

## الأجهزة

- قارئ الباركود الذي يعمل كلوحة مفاتيح غالباً يمكنه إدخال الرقم في حقل البحث.
- الطباعة الحالية تستخدم نافذة طباعة المتصفح، ويمكن اختيار طابعة حرارية من إعدادات الطباعة إذا كان النظام والتعريف يدعمانها.
- Bluetooth ESC/POS والميزان المتصل عبر RS-232/LAN/USB يحتاجان معرفة الشركة والموديل والبروتوكول، وقد يتطلبان تطبيق وسيط أو برنامجاً محلياً. لا يوجد توافق مضمون قبل اختبار الجهاز.

## ملاحظات

- العملة المعروضة: الدينار الجزائري (دج).
- الأرباح المعروضة تقديرية من تكلفة المنتج المخزنة وقت البيع.
- لا توجد حالياً معالجة ضريبية أو محاسبة قانونية أو مرتجعات جزئية أو إغلاق صندوق محاسبي كامل.
